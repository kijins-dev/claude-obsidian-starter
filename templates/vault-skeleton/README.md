# Vault構造（このフォルダ一式をあなたのObsidian Vaultにコピーする）

| フォルダ | 役割 | 誰が書くか |
|---|---|---|
| `00_受信箱/` | 未整理の情報の一時置き場。毎朝の自動整理がここから拾う | 人間・自動 |
| `01_01_デイリーノート/{YYYY}年/` | セッション記録の時系列ログ。**必ず年フォルダの中に置く** | フックが自動 |
| `02_プロジェクト/` | プロジェクトごとの記録・設計判断。`{番号}_{プロジェクト名}/` 形式 | 人間・AI |
| `04_技術ドキュメント/` | 再利用する技術知見のwiki。毎朝の自動整理が生成 | 自動 |
| `05_会議記録/` | 議事録の置き場 | 人間・自動 |
| `07_アーカイブ/` | 終了したものの保管庫。削除の代わりにここへ移動 | 人間 |
| `Clippings/` | Webクリップの受け皿（Obsidian Web Clipper等） | 人間 |

## ルール（重要）

- **ルート直下に.mdファイルを置かない**。必ずどこかのフォルダに入れる
- デイリーノートは `01_01_デイリーノート/2026年/2026-01-15.md` のように**年フォルダ配下**が正しい場所
- `02_プロジェクト/` の各フォルダには `INDEX.md`（そのプロジェクトの状態がわかる目次）を1つ置く
